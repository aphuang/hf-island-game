# 飛吧！華府島嶼大冒險

推廣華府旅行社行程的擲骰子遊戲網頁（純前端，無需框架）。

## 檔案
| 檔案 | 用途 |
|---|---|
| `index.html` | 頁面結構 |
| `style.css` | 樣式（含手機版 RWD） |
| `game.js` | 遊戲邏輯、地圖繪製、讀取 Sheets |
| `data.js` | **設定檔**：Sheet ID、抽獎送出網址、國家／地區對照表、備援資料 |
| `apps-script.gs` | 抽獎名單接收程式（貼到 Google Apps Script） |

## 上線前要做的事
1. **開放試算表讀取**：行程試算表 →「共用」→ 一般存取權改成「知道連結的任何人：檢視者」。
   沒開放時網頁會自動改用 `data.js` 裡的備援資料（2026/11/03 快照）。
2. **抽獎名單**：依 `apps-script.gs` 開頭的步驟部署，把網址填進 `data.js` 的 `ENTRY_ENDPOINT`。
   沒填時是測試模式，資料只存在瀏覽器裡。
3. 把整個資料夾上傳到網站主機即可（需用 http/https 開啟，不能直接雙擊 html）。

## 貝殼幣規則（可在 data.js 調整）
- `GAP_MIN` / `GAP_MAX`：島與島之間的步數點（目前 2～3）
- 步數點「幸運貝殼」和「機會卡」交錯排列
- 每局目標行程 = 目的地國家最便宜的行程；起始貝殼幣固定 `START_COINS`（1,000）
- 幸運貝殼依「還差多少」和「離目的地多遠」計算（`COIN_GAIN`、`SHELL_EVERY`、`SHELL_MIN`），約 3/4 的玩家第一次抵達就夠錢，一局平均約 9 次擲骰
- 海鷗 `GULL_LOSS`（行程價 4～8%）、弄丟錢包 `WALLET_LOSS`（8～14%）
- 目的地至少離飛機航線一圈的 `TARGET_MIN_DIST`（30%）；離目的地 `REVERSE_SAFE`（15）步內不會抽到反方向飛
- 飛到目的地就停下來（剩下的步數不用飛）；貝殼幣 ≥ 行程價才算完成，否則再飛一圈
- 機會卡 7 種機率相同：順風飛行（+3 步）、噴射氣流（選一座島飛過去）、幸運加倍（下一擲 ×2）、調皮海鷗（叼走貝殼幣）；壞卡：逆風倒退（退 1～3 步）、弄丟錢包、反方向飛。壞卡每局最多 `BAD_CARD_MAX` 次（海鷗不計）
- 島嶼圖鑑：停在島上就收集，存在玩家瀏覽器；`DEX_REWARDS` 設定集滿 5／10／全部國家的貝殼幣獎勵，全部集滿另外解鎖「環島大獎」抽獎（`GRAND_PRIZE_TEXT`）
- 抽獎資料填過一次就記在玩家瀏覽器，之後抵達目的地會自動登記，不用重填；名單的「獎項」欄分成一般抽獎／環島大獎，同一支手機每種獎項只記一次

## 新增地區
Sheet 新增的「地區城市」若對應不到國家，瀏覽器 console 會列出來；到 `data.js` 的 `COUNTRIES` 把關鍵字加進對應國家的 `keys`。
新增國家需另外在 `game.js` 的 `LANDMARKS` 畫一個地標（沒畫也能運作，只是島上沒有建築）。
